# EduBuddy UI 设计文档

**版本**：V1.0  
**日期**：2026-05-28  

---

## 1. 设计原则

### 1.1 核心理念
- **专注学习**：界面简洁无干扰，突出内容本身
- **清晰层次**：信息层次分明，引导学生流畅操作
- **鼓励反馈**：学习进度可视化，给予正向激励
- **减少认知负担**：操作路径短，交互逻辑直觉化

### 1.2 设计风格
- 风格：扁平化 + 卡片式设计
- 氛围：清新明亮，带有蓝绿主色调（学术感 + 活力感）
- 适合中学生的年龄审美，不过于幼稚也不过于严肃

## 2. 视觉设计规范

### 2.1 色彩系统

```
主色（Primary）：
  蓝色系
  --color-primary-50:  #EFF6FF
  --color-primary-100: #DBEAFE
  --color-primary-500: #3B82F6   ← 主要按钮、链接、高亮
  --color-primary-600: #2563EB   ← hover 状态
  --color-primary-700: #1D4ED8   ← active 状态

强调色（Accent）：
  青绿色（代表"学习成功/进步"）
  --color-accent-500:  #10B981   ← 正确、已完成、成功
  --color-accent-100:  #D1FAE5

警示色：
  --color-warning-500: #F59E0B   ← 待复习、模糊掌握
  --color-error-500:   #EF4444   ← 错误、未掌握

中性色：
  --color-gray-50:  #F9FAFB     ← 页面背景
  --color-gray-100: #F3F4F6     ← 卡片背景
  --color-gray-200: #E5E7EB     ← 分割线、边框
  --color-gray-500: #6B7280     ← 次要文字
  --color-gray-700: #374151     ← 主要文字
  --color-gray-900: #111827     ← 标题
```

**掌握程度颜色映射**：
- ❌ 未掌握 → `#EF4444` 红色
- ⚠️ 模糊   → `#F59E0B` 黄色
- ✅ 已掌握 → `#10B981` 绿色

### 2.2 字体规范

```
字体家族：
  中文：PingFang SC, Noto Sans SC, sans-serif
  英文/数字：Inter, -apple-system, sans-serif
  代码/公式：JetBrains Mono, monospace

字体大小：
  --text-xs:   12px  （标签、辅助信息）
  --text-sm:   14px  （正文次要内容）
  --text-base: 16px  （正文）
  --text-lg:   18px  （小标题）
  --text-xl:   20px  （模块标题）
  --text-2xl:  24px  （页面标题）
  --text-3xl:  30px  （大标题）

行高：正文 1.6，标题 1.3
```

### 2.3 间距系统（基于 8px 网格）

```
--space-1:  4px
--space-2:  8px
--space-3:  12px
--space-4:  16px
--space-5:  20px
--space-6:  24px
--space-8:  32px
--space-10: 40px
--space-12: 48px

```

### 2.4 圆角与阴影

```
圆角：
  --radius-sm:   4px   （标签、小按钮）
  --radius-md:   8px   （卡片、输入框）
  --radius-lg:   12px  （弹窗、大卡片）

  --shadow-md: 0 4px 12px rgba(0,0,0,0.10)
  --shadow-lg: 0 8px 24px rgba(0,0,0,0.12)
```

## 6. 交互动效规范

### 6.1 页面切换
- 路由切换：fade-in 过渡（150ms ease）

### 6.2 AI 打字机效果
- 流式输出时，新字符以渐显方式出现（避免画面跳动）

### 6.3 卡片交互
- hover：轻微上移（`transform: translateY(-2px)`）+ 加深阴影（`transition: 200ms ease`）
- 点击：`transform: translateY(0)` 下沉反馈

### 6.4 加载状态
- 骨架屏（Skeleton Loader）：列表加载时使用
- AI 回答加载中：显示跳动的三点 `...` 动画

### 6.5 成功/错误反馈
- 操作成功：顶部 Toast 通知（绿色，2秒自动消失）
- 操作失败：顶部 Toast 通知（红色，3秒消失 + 手动关闭）
