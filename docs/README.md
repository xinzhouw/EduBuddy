## 产品简介

**EduBuddy** 是一款面向中学生的 AI 驱动个性化学习助手 Web 应用。

### 核心功能（V1.0）

| 功能 | 说明 |
|------|------|
| 🤖 AI 问答解题 | 支持所有中学学科，结构化分步解析，流式输出 |
| 📝 笔记管理 | 富文本笔记 + AI 总结 + 自动生成知识卡片 |
| 📚 练习题生成 | AI 按学科/知识点/难度/题型生成练习，自适应难度推荐 |
| ❌ 错题本 | 自动/手动录入，AI 解题讲解，间隔复习（艾宾浩斯遗忘曲线） |
| 📅 学习计划 | 根据考试日期自动生成学习计划，番茄钟计时器 |
| 📄 文档解析 | 上传 PDF/Word/图片，AI 提取知识点/摘要/出题 |
| 📊 学习统计 | 学习时长趋势、学科正确率、错题分布、打卡热力图 |

### 技术栈

- **前端**：Vue 3 + TypeScript + Tailwind CSS + Element Plus
- **后端**：Python FastAPI + SQLAlchemy + SQLite
- **AI**：OpenAI GPT-4o（流式输出）
- **部署**：Docker Compose
