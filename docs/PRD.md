## 1. 产品概述

### 1.1 产品定位

EduBuddy 是一款面向**中学生**的 AI 驱动个性化学习助手 Web 应用。通过人工智能技术，帮助学生高效解题、整理知识、练习备考，实现个性化学习体验。

### 1.2 目标用户

- **主要用户**：初中生、高中生（13~18岁）
- **使用场景**：
  - 课后作业遇到不会的题
  - 备考复习，整理知识点
  - 巩固练习，查漏补缺
  - 自主制定学习计划

### 1.3 核心价值

| 痛点 | EduBuddy 解决方案 |
|------|----------------|
| 遇到难题没人解答 | AI 即时解题，步骤详细 |
| 错题重复犯 | 错题本 + 间隔复习机制 |
| 不知道如何备考 | AI 生成个性化学习计划 |
| 练习题资源匮乏 | AI 按需生成各难度练习题 |
| 笔记杂乱难整理 | AI 自动整理归纳知识点 |

## 2. 功能模块详细说明

### 2.1 用户认证模块

#### 2.1.1 功能列表
- 用户注册（邮箱 + 密码）
- 用户登录（邮箱 + 密码）
- JWT Token 认证
- 修改密码
- 个人信息设置（昵称、年级、头像）

#### 2.1.2 年级设置
学生注册时选择年级：
- 初一 / 初二 / 初三（中考备考）
- 高一 / 高二 / 高三（高考备考）

年级信息影响：AI 出题范围、难度推荐、学科范围。

---

### 2.2 AI 问答解题模块

#### 2.2.1 功能描述
学生输入任何中学学科问题，AI 给出结构化、分步骤的详细解析。

#### 2.2.2 支持学科
数学、物理、化学、生物、语文、英语、历史、地理、政治（道德与法治）

#### 2.2.3 输入方式
- 文字输入（支持粘贴题目）
- 图片上传（OCR 识别题目文字）
- 支持 LaTeX 数学公式输入

#### 2.2.4 AI 回答格式（结构化输出）
```
【解题思路】
简要描述解题方向和用到的核心知识点。

【详细步骤】
第一步：...
第二步：...
第N步：...

【最终答案】
明确标注最终结果。

【相关知识点】
- 知识点1
- 知识点2

【易错提醒】
提示学生容易犯的错误。
```

#### 2.2.5 可靠性保障机制
1. **System Prompt 约束**：限定只回答中学学科问题，拒绝不相关请求
2. **课程大纲约束**：解题方法限定在中学教学大纲范围内
3. **用户反馈**：每条回答可点击 👍/👎，差评可选择原因并触发重新回答
4. **追问功能**：学生可以在当前对话中继续追问，实现多轮对话

#### 2.2.6 问答历史
- 按日期保存所有问答记录
- 支持搜索历史记录
- 支持将某条问答"加入错题本"

### 2.3 笔记管理模块

#### 2.3.1 功能列表
- 创建/编辑/删除笔记（富文本编辑器）
- 按学科分类管理笔记
- 支持 LaTeX 公式插入
- 图片插入

#### 2.3.2 AI 辅助功能
| 功能 | 说明 |
|------|------|
| AI 总结 | 输入笔记内容，AI 提炼核心知识点，生成结构化摘要 |
| AI 生成知识卡片 | 从笔记中自动抽取关键概念，生成 Flashcard |
| AI 补充知识 | 基于笔记主题，AI 补充相关延伸知识 |

#### 2.3.3 知识卡片（Flashcard）
- 正面：概念/问题
- 背面：解释/答案
- 支持手动创建和 AI 自动生成
- 支持复习模式（翻转查看）

### 2.4 练习题生成模块

#### 2.4.1 生成方式
- 学生选择：学科 → 知识点 → 题型 → 难度 → 数量
- AI 生成对应练习题

#### 2.4.2 难度等级

| 等级 | 名称 | 说明 |
|------|------|------|
| 1 | 🌱 基础 | 基本概念，直接应用 |
| 2 | 📘 中等 | 综合运用，中考常见题型 |
| 3 | 🔥 困难 | 拔高题、联考常见压轴题 |
| 4 | 🏆 挑战 | 竞赛级别，超纲拓展 |

#### 2.4.3 自适应难度推荐
- 系统记录每个知识点的历史答题正确率
- 正确率 > 80%：推荐升一档难度
- 正确率 40%~80%：维持当前难度
- 正确率 < 40%：推荐降一档难度

#### 2.4.4 支持题型
- 单选题（4个选项）
- 多选题
- 填空题
- 判断题
- 简答/计算题（给出参考答案和评分要点）

#### 2.4.5 答题与评分
- 客观题（选择、填空、判断）：系统自动判题
- 主观题（简答、计算）：AI 评分，给出参考答案对比，学生自评
- 答题完成后显示：正确率、用时、AI 解析（错误题目自动展开解析）

#### 2.4.6 练习记录
- 保存每次练习的结果
- 错误题目自动进入错题本

### 2.5 错题本模块

#### 2.5.1 错题来源
1. **自动录入**：练习题答错时自动进入错题本
2. **手动录入**：
   - 文字输入题目
   - 拍照上传（OCR 识别）
3. **从问答历史标记**：问答页面点击"加入错题本"

#### 2.5.2 错题记录内容
每道错题存储以下信息：
- 题目内容（文字/图片）
- 正确答案
- 学生的错误答案（如有）
- 学科 / 知识点标签
- 录入时间
- 掌握程度（未掌握/模糊/已掌握）
- 下次复习时间

#### 2.5.3 AI 解题示例功能（核心）
每道错题提供"AI 讲解"功能，展示内容：

```
【解题思路】解题方向分析

【详细步骤】逐步推导过程

【最终答案】明确答案

【错误分析】（针对手动录入的题目，分析常见错误原因）

【相关知识点】涉及知识点列表

【易错提醒】容易犯的错误
```

**交互特性**：
- 支持逐步展示（"下一步"点击式呈现），鼓励学生主动思考
- 学生可追问 AI（多轮对话）
- 点击"我已理解 ✅" → 更新掌握程度
- 点击"出一道类似的题" → 立即生成同类型练习题

#### 2.5.4 间隔复习（Spaced Repetition）
基于艾宾浩斯遗忘曲线，系统智能安排复习时间：

| 复习次数 | 下次复习间隔 |
|---------|------------|
| 第1次复习后 | 1 天后 |
| 第2次复习后 | 3 天后 |
| 第3次复习后 | 7 天后 |
| 第4次复习后 | 14 天后 |
| 第5次复习后 | 30 天后（标记为已掌握）|

复习模式：
- 进入"闯关模式"：隐藏答案，要求学生重新作答
- 答对：进入下一个间隔周期
- 答错：重置复习周期，重新从第1次开始

#### 2.5.5 错题筛选与管理
- 按学科筛选
- 按掌握程度筛选（未掌握/模糊/已掌握）
- 按日期排序
- 支持删除错题
- 批量标记掌握程度

### 2.6 学习计划模块

#### 2.6.1 计划生成
学生输入：
- 备考学科（多选）
- 考试日期
- 每天可学习时长（小时）
- 薄弱学科标记（可选）

系统输出：
- 按天分配的学习任务
- 每项任务包含：学科、知识点、预计时长、任务类型（学习/练习/复习）
- 考试前1周自动安排综合复习

#### 2.6.2 计划管理
- 任务完成后打勾
- 进度条可视化（今日完成度/整体完成度）
- 计划可手动调整（拖拽排序、修改时长）
- 漏做任务自动延期处理

#### 2.6.3 番茄钟计时器
- 标准：25分钟专注 + 5分钟休息
- 可自定义时长
- 休息时给出学习小贴士
- 记录每日番茄数

### 2.7 文档上传与 AI 解析模块

#### 2.7.1 支持格式
- PDF（教材、讲义、试卷）
- Word (.docx)
- 图片（JPG/PNG，适合拍照上传）

#### 2.7.2 文件限制
- 单文件最大：20MB
- 图片最大：5MB

#### 2.7.3 AI 解析功能

| 功能 | 说明 |
|------|------|
| 提取知识点 | 从文档中提取核心知识点，结构化列表展示 |
| 生成摘要 | 对长文档生成简洁摘要 |
| 基于文档出题 | 根据文档内容，AI 生成练习题 |
| 划词解释 | 选中文档中的文字，获取解释 |

#### 2.7.4 文档管理
- 上传的文档保存在个人资料库
- 按学科分类
- 支持删除

### 2.8 学习统计模块

#### 2.8.1 统计维度
- 每日/每周/每月学习时长
- 各学科学习时长占比
- 练习题正确率趋势
- 错题本知识点分布（薄弱点分析）
- 连续打卡天数

#### 2.8.2 可视化图表
- 折线图：学习时长趋势
- 柱状图：各学科学习量
- 雷达图：各学科掌握程度
- 热力图：学习活跃度日历（类 GitHub Contribution）

## 3. 非功能性需求

### 3.1 性能
- AI 问答响应时间：流式输出，首字响应 < 2秒
- 页面加载时间：< 3秒
- 文档解析时间：< 30秒（20MB文档）

### 3.2 安全性
- 所有接口需 JWT 认证
- 密码 bcrypt 加密存储
- 用户数据隔离，只能访问自己的数据
- AI 内容安全过滤（避免不当内容）

### 3.3 兼容性
- 支持主流浏览器：Chrome、Firefox、Safari、Edge（最新两个版本）
- 响应式设计：支持桌面端（1280px+）和平板端（768px+）
