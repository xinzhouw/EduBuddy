# EduBuddy 产品上下文

## 为什么存在这个项目

中学生在学习过程中面临以下典型痛点：
- 遇到难题无人即时解答，作业卡顿效率低
- 错题重复犯，缺乏有效的错题管理和复习机制
- 备考时不知道如何合理分配时间和制定计划
- 练习题资源匮乏，获取适合自己难度的题目困难
- 笔记杂乱，难以归纳整理知识点

EduBuddy 通过 AI 技术一站式解决上述问题，成为学生的"全天候学习伙伴"。

## 核心用户体验目标

### 1. AI 问答解题
- 学生粘贴或输入题目，AI 以结构化格式输出解析
- 输出格式：【解题思路】→【详细步骤】→【最终答案】→【相关知识点】→【易错提醒】
- 支持流式打字机效果（SSE），首字响应 < 2秒
- 支持追问（多轮对话），每条回答可 👍/👎 反馈
- 支持图片上传（OCR 识别题目）

### 2. 笔记管理
- 富文本编辑器，支持 LaTeX 公式和图片插入
- AI 一键总结笔记，提炼核心知识点
- AI 自动生成知识卡片（Flashcard），支持翻转复习

### 3. 练习题生成
- 学生选择学科→知识点→题型→难度→数量
- AI 生成对应题目，自动判题
- 自适应难度：正确率 > 80% 推荐升档，< 40% 推荐降档
- 错题自动进入错题本

### 4. 错题本（核心功能）
- 三种录入方式：练习答错自动录入、手动录入、从AI问答标记
- 间隔复习（艾宾浩斯遗忘曲线）：1天→3天→7天→14天→30天
- AI 逐步讲解（"下一步"点击式呈现，鼓励主动思考）
- 掌握程度标记：未掌握 / 模糊 / 已掌握
- "出一道类似的题"快速跳转练习

### 5. 学习计划
- 输入备考学科、考试日期、每日可学习时长
- AI 生成按天分配的学习任务
- 番茄钟计时器（25分钟专注 + 5分钟休息，可自定义）
- 任务完成打勾，漏做任务自动延期

### 6. 文档上传
- 上传 PDF/Word/图片（最大 20MB）
- AI 提取知识点、生成摘要、基于文档出题

### 7. 学习统计
- 多维度可视化：折线图（时长趋势）、柱状图（各学科学习量）、雷达图（掌握程度）、热力图（日历活跃度）
- 连续打卡天数、各学科正确率趋势

## 非功能性要求

| 指标 | 目标 |
|------|------|
| AI 首字响应 | < 2秒（流式） |
| 页面加载 | < 3秒 |
| 文档解析 | < 30秒（20MB） |
| 浏览器兼容 | Chrome/Firefox/Safari/Edge 最新两版 |
| 响应式 | 桌面端（1280px+）和平板端（768px+） |

## AI 内容安全策略
- System Prompt 限定只回答中学学科问题
- 解题方法限定在中学教学大纲范围内
- 对非学习相关问题礼貌拒绝
- 每条 AI 回答可用户反馈（差评触发重新回答）
