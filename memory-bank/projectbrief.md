# EduBuddy 项目简介

## 项目名称
EduBuddy — AI 驱动的中学生个性化学习助手

## 版本
V1.0（当前开发阶段）

## 项目目标
构建一款面向初中生和高中生（13~18岁）的 Web 应用，通过 AI 技术帮助学生：
- 即时获取解题帮助（AI 问答）
- 管理错题并通过间隔复习巩固知识
- 生成个性化学习计划
- 按需生成练习题
- 自动整理笔记知识点

## 核心功能模块（V1.0 范围）
1. **用户认证** — 注册/登录，JWT 认证，年级设置
2. **AI 问答解题** — 流式输出，多轮对话，👍/👎 反馈
3. **笔记管理** — 富文本编辑，AI 总结，知识卡片（Flashcard）
4. **练习题生成** — 按学科/知识点/难度/题型 AI 生成，自动判题
5. **错题本** — 自动/手动录入，间隔复习（艾宾浩斯），AI 讲解
6. **学习计划** — AI 生成按天任务，番茄钟，进度追踪
7. **文档上传与解析** — PDF/Word/图片，AI 提取知识点/生成摘要/出题
8. **学习统计** — 多维度可视化，折线图/柱状图/雷达图/热力图

## 目标用户
初中生（初一~初三）、高中生（高一~高三）

## 支持学科
数学、物理、化学、生物、语文、英语、历史、地理、政治（道德与法治）

## 版本规划
| 版本 | 功能范围 |
|------|---------|
| MVP | AI问答 + 笔记管理 + 练习题生成 |
| V1.0 | MVP + 错题本 + 学习计划 + 文档上传 + 学习统计 |
| V2.0 | 成就系统 + 社交功能 + 移动端App |
